# 公共知识包 · 知识目录

本目录全平台只有一份，通过 `workspace/knowledge-base` 软链接入工作区。按约定**只读**：任何贡献都走 `pending/` 候选 + 跨组评审，不直接写入正式分类。

目录与团队知识同构，多一个 `pending/`：

| 目录 | 放什么 |
| --- | --- |
| `pending/` | 待审候选，标 `status: pending`，不进索引、不参与默认检索 |
| `domain/` | 跨项目通用领域模型 |
| `rules/` | 全局架构原则 |
| `cases/` | 跨组可复用案例 |
| `runbooks/` | 通用操作与验证手册 |
| `decisions/` | 重大架构决策 |
| `workflows/` | 研发标准流程 |
| `index/` | 全局检索索引 |

当前正式条目 0 条，候选 1 条。目录结构与分类约定见 `catalog.md`。
