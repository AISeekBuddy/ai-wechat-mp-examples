# 团队知识目录

本目录由示例工作组自己维护，通过 `workspace/knowledge` 软链接入工作区，**可写**。本体不复制进项目。

| 目录 | 放什么 |
| --- | --- |
| `runbooks/` | 排查与操作手册 |
| `cases/` | 单次问题复盘（本组内） |
| `domain/` | 本领域对象与关系 |
| `rules/` | 本组长期必须遵守的约定 |
| `decisions/` | 本组决策记录 |
| `workflows/` | 本组标准流程 |
| `index/` | 检索索引，先扫索引再读正文 |

当前正式条目 1 条，见 `index/documents.json`。候选不放在这里，公共层才有 `pending/`。
