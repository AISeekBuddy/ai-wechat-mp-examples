# 团队知识分类约定

| 目录 | 写入判据 | 例子 |
| --- | --- | --- |
| `runbooks/` | 下次遇到同类现象，第一步该做什么 | 同名配置项返回多条的排查手册 |
| `cases/` | 只在本组内部有参考价值的一次性复盘 | 某次发布后的回滚记录 |
| `domain/` | 本组特有的对象、关系和术语 | 本组单据状态流转 |
| `rules/` | 长期必须遵守、边界明确的约定 | 改动前必须先跑哪组回归 |
| `decisions/` | 本组做过的技术选择及理由 | 为什么选这套缓存策略 |
| `workflows/` | 本组标准流程 | 提测到发布的步骤 |

一次实现经验留在 `cases/` 或 `runbooks/`。跨组仍成立的机制不写在这里，交给公共知识包。
