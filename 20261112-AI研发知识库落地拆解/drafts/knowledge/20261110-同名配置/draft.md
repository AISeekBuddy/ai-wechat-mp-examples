# 配置项返回多条 · 会话草稿

- 摘要：同一组件返回多条同名配置项、条件不一致，根因是配置存储里新旧两套没有按组件覆盖去重
- 关键词：配置项 / 同名 / 条件不一致 / 双套存储 / 去重
- 会话主题：排查「条件时对时不对」
- 主要动作：怀疑前端渲染重复 → 查缓存 → 翻配置存储 → 定权威配置 → 清遗留套
- 状态：待处理

## 这次聊明白了什么

1. 同名配置出现多条，先查存储里的历史双套，别先查前端。
2. 条件不一致来自两条持久化的表达式，渲染层看到的只是结果。
3. 动手前先定权威配置，只改其中一处没有用。
4. 下次第一步：记下组件名和重复项名，直接对照两张配置表里同一组件的定义。
